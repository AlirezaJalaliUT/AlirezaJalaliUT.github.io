# راهنمای راه‌اندازی سایت آزمایشگاه تصفیه آب

این فایل **فقط راهنمای شما** است؛ خود وب‌سایت و تمام عنوان‌های پنل Pages CMS انگلیسی هستند.

## انتشار رایگان با GitHub Pages

1. در GitHub یک حساب رایگان بسازید. بهتر است مالک نهایی سایت خود استاد یا یک سازمان دانشگاهی باشد.
2. یک مخزن **Public** به نام دقیق `USERNAME.github.io` ایجاد کنید؛ به‌جای `USERNAME` نام کاربری GitHub قرار می‌گیرد.
3. فایل ZIP را در کامپیوتر باز کنید و **محتوای درون آن** (نه پوشه مادر) را به ریشه مخزن GitHub آپلود کنید. فایل مخفی `.pages.yml` را فراموش نکنید.
4. به `Settings → Pages` بروید و `Deploy from a branch` با `main` و `/(root)` را فعال کنید.
5. پس از موفقیت انتشار، آدرس `https://USERNAME.github.io/` را باز کنید.

## فعال‌سازی مدیریت آسان برای استاد

1. وارد https://app.pagescms.org شوید.
2. با GitHub وارد شوید و دسترسی برنامه به همین مخزن را تأیید کنید.
3. مخزن را باز کنید؛ قسمت‌های «Site Settings & Contact»، «Publications»، «Team Members & Alumni»، «Open Positions» و بقیه بخش‌ها در پنل هستند.
4. برای افزودن عضو گروه، خبر، مقاله یا موقعیت، New را بزنید؛ فیلدها را پر کنید و گزینه **Published on Website** را فعال کنید.
5. Save را بزنید. بعد از ثبت تغییر در GitHub، سایت به‌صورت خودکار مجدداً ساخته می‌شود.

## پیش از معرفی رسمی به استاد

- عکس واقعی و تأییدشده استاد را در قسمت **Professor Portrait** آپلود کنید.
- اسم انگلیسی رسمی آزمایشگاه، عنوان دانشگاهی و متن زندگی‌نامه را با استاد هماهنگ کنید.
- مشخصات دانشجویان، پروژه‌ها، اخبار، جوایز و پوزیشن‌ها هنوز عمداً خالی است، چون اطلاعات معتبر در اختیار ما نیست.
- چند مقاله با DOI معتبر در سایت قرار گرفته‌اند؛ تأیید نهایی فهرست مقالات با استاد است.
- در مخزن عمومی GitHub، حتی فایل‌های غیرمنتشرشده نیز برای همه قابل مشاهده‌اند؛ **داده محرمانه آپلود نکنید**.
- مدیریت نوشته‌ها، تصویرها و مقالات با CMS آسان است، ولی **تغییر اساسی طراحی و ساختار** همچنان به ویرایش کد نیاز دارد.

جزئیات کامل در `README.md` و منابع در `SOURCES_AND_FACT_CHECK.md` آمده است.
